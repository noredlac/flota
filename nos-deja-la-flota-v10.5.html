📥 Importar Preguntas

Se agregarán a la estación que tengas abierta en la pestaña "Preguntas".

Pega un arreglo JSON con tus preguntas. Cada una necesita tipo ("multiple", "arreglarIf" o "completar"), titulo, enunciado, y según el tipo: opciones + correcta (índice), o respuestasValidas.

📖 Ver estructura completa y qué significa cada línea 
[
  {
    // "tipo": define cómo se responde esta pregunta. Valores posibles:
    //   "multiple"   → el estudiante elige entre varias opciones (A, B, C, D)
    //   "arreglarIf" → igual que "multiple", pero pensado para corregir un error de código
    //   "completar"  → el estudiante ESCRIBE la respuesta con el teclado
    "tipo": "multiple",

    // "dificultad": solo afecta el color del sello visual. Valores: "facil" o "dificil"
    "dificultad": "facil",

    // "tiempoBaseSegundos": segundos de penalización si falla esta pregunta (número)
    "tiempoBaseSegundos": 120,

    // "titulo": nombre corto del reto, aparece arriba de la tarjeta
    "titulo": "Listas en Python",

    // "enunciado": la pregunta completa que lee el estudiante
    "enunciado": "¿Cómo se crea una lista vacía?",

    // "codigo": el bloque de código gris que se muestra (usa \n para saltos de línea)
    "codigo": "lista = ___",

    // ↓↓↓ SOLO si tipo es "multiple" o "arreglarIf" ↓↓↓
    // "opciones": arreglo con las 2 a 4 alternativas que verá el estudiante
    "opciones": ["[]", "()", "{}", "None"],
    // "correcta": en qué POSICIÓN de "opciones" está la respuesta correcta.
    //   Se cuenta desde 0: la primera opción es 0, la segunda es 1, la tercera es 2...
    "correcta": 0,

    // ↓↓↓ SOLO si tipo es "completar" (en vez de opciones/correcta) ↓↓↓
    // "respuestasValidas": ["for", "for item in menu"]  ← lista de textos aceptados

    // "explicacion": por qué es correcta (se muestra solo cuando ACIERTA)
    "explicacion": "Una lista vacía se crea con corchetes [].",

    // "historia": (opcional) frase corta de la narrativa del juego para esta pregunta
    "historia": "Vas caminando por el sendero cuando un amigo te para a preguntarte esto..."
  }
]
